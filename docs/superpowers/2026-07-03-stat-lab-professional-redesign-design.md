# Stat-Lab 专业级视觉升级设计

> 日期: 2026-07-03
> 状态: 已批准
> 风格: Linear 风格 —— 精致冷峻

## 设计决策

| 维度 | 决策 |
|------|------|
| 风格 | Linear 风格 —— 精致冷峻 |
| 导航 | 顶部导航 + 左侧边栏 |
| 动效 | 丰富动效（staggered fade-in、弹性 hover、数字滚动、骨架屏） |
| 主题 | 单一浅色主题，专注打磨 |
| 字体 | Inter 系列 |
| 配色 | 浅灰底 `#fafafa` + 白卡片 + 品牌蓝 `#3b82f6` |
| 范围 | 全站 16 个 HTML + 6 个 CSS + 2 个 JS 全面重构 |

## 视觉系统

### 配色

- **背景**: `#fafafa`（极浅灰，非纯白）
- **卡片**: `#ffffff` + 1px `#e5e7eb` 边框 + 微妙阴影
- **文字三级**: 主标题 `#111827` / 正文 `#374151` / 辅助 `#6b7280`
- **品牌色**: 冷蓝 `#3b82f6`
- **语义色**: 成功 `#10b981` / 警告 `#f59e0b` / 危险 `#ef4444`

### 字体

- **显示/正文**: Inter, -apple-system, BlinkMacSystemFont, system-ui
- **代码**: JetBrains Mono, Fira Code, monospace
- **字号层级**: 基准 14px, H1=32px, H2=24px, H3=18px

### 间距

- 4px 基准网格: 4, 8, 12, 16, 24, 32, 48, 64

## 布局

### 导航栏

- 高度 56px, 白色背景 + 底部 1px 分隔线
- 左侧: 品牌 logo (文字 + 图标)
- 中间: 全局导航链接
- 右侧: 学科切换下拉

### 知识点页面

- 左侧固定侧边栏: 240px, 目录导航 + 活跃项高亮
- 右侧内容区: max 800px 居中
- 面包屑: 细文字 + 分隔符

### 首页

- Hero 区域: 居中标题 + 副标题 + 渐变分割线
- 学科卡片: 2 列 grid, 细边框 + 悬浮阴影
- 图标: SVG 风格替代 emoji

### 测验/计算器/实验页

- 居中单栏, max-width 720px
- 大间距呼吸感

## 动效

### 页面

- 内容区 staggered fade-in (每个元素延迟 60ms)
- 卡片 grid 相同 stagger 动画

### 卡片

- Hover: 上移 4px + 阴影加深 + 边框变深
- 点击: scale 0.98 反馈

### 导航

- 链接 hover: 底部滑入下划线
- 学科切换: 平滑过渡

### 测验

- 选项选中: 边框变蓝 + 背景变化
- 正确: 绿色边框 + 打勾弹入
- 错误: 红色边框 + 叉号弹入
- 分数: 数字滚动动画

### 微交互

- 按钮: 缩放反馈
- 进度条: 平滑宽度过渡
- 加载: 骨架屏替代 spinner
